☁️ **Salesforce** is the world's No.1 CRM software that helps build customizable apps for businesses to manage their customer data ,automate business processes ,manage sales, marketing and services.

---

It's both PAAS and SAAS
1. PAAS - Provides platform for developers to build and run apps.
2. SAAS - Provides software to manage everything online without any installation or maintenance.

# Workflow of Salesforce App Building

### 1. Data Modeling 
```
a. Custom Objects , Fields , Relationships - Lookup(48) / Master-Detail(2) , Junction Objects for many to many
b. Setup validation Rules, formula fields, roll-up summary
```

### 2. Security and Access
```
a. Profile /Permission set for object and field level access
b. OWD (Org-Wide Default) + Sharing Rules
c. Field level security audit
```

### 3. Business Logic(Apex)
```
a. One trigger per object → handler class pattern : The trigger just routes events, the handler decideswhat happens.
```

### 4. Automation
```
a. Record Triggered Flow for declarative logic.
b. Scheduled/Batch apex for async/bulk processes.
```
